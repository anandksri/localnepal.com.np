# LocalNepal

LocalNepal is a digital marketing website focused on presenting marketing services, portfolio work, and client-focused digital experiences.

## Features

- Service and portfolio sections
- About and work sections
- Testimonials
- Contact and call-to-action sections
- Responsive navigation and mobile menu
- Animated visual effects

## Tech Stack

- HTML5
- Tailwind CSS via CDN
- JavaScript
- Inter font
- Phosphor Icons

## Getting Started

Clone the repository and open `index.html` in a browser, or serve the project with a local HTTP server.

## Notes

The project currently uses CDN-hosted frontend dependencies. For production hardening, dependency pinning or a build-based frontend setup can be considered.
